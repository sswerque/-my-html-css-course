# Проект «Суши-бар» (HTML + CSS)

Учебный проект по вёрстке: адаптивное меню с карточками роллов, форма заказа и стильные секции.

## Что реализовано

- Семантическая вёрстка на HTML5.
- Стилизация на чистом CSS (Flexbox/Grid).
- Адаптивность под мобильные устройства.
- Подключение кастомных шрифтов и иконок.
